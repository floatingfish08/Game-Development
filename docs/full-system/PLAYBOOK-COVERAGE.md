# Playbook implementation coverage

| Playbook requirement | Runtime implementation |
| --- | --- |
| Live facilitated multiplayer scenario | Shared display, private instruments, facilitator console, synchronized server state |
| Suggested 4–7 player configurations | Exact 4, 5, 6, and 7-player responsibility maps, plus the requested 2-player mode |
| Unequal information | Stage-specific private card per role or combined responsibility bundle |
| Seven challenges | Seven timed, consequential stages with fail-forward resolution |
| Progressive degraded signal | Shared and facilitator transmission whose integrity and transcript respond to preserved evidence |
| Chemical, flood, storm, and cordon pressure | Persistent incident telemetry with a staged external-movement window and official-status race |
| Physical investigation | Three-move Outside Run with runner, destination, abort condition, exposure, and three guidance bursts |
| Partial respirator and air meter | Scarce filter state, rising ppm reading, 18 ppm forced withdrawal, and later Mara/hatch allocation |
| Mara rescue and crew survival | Parallel finale state and explicitly separate outcome labels |
| Physical lock and external signal matrix | Two-round finale with Lock, Signal, and People lanes and named owners |
| Canonical outcomes | Clean Rescue, Costly Rescue, Last Broadcast, Joined Below, Flee Ridge, Filed Safe, Station Loss |
| Participant care | Required pre-start briefing, private off-ramp language, Safety Pause, observer mode |
| Single facilitator | One console controls timing, prompts, safety, recovery, resolution, and ending confirmation |
| Structured 20–25 minute debrief | Six synchronized steps, facilitator notes, individual first-step capture |
| Role map vs readiness profiles | Separate responsibility-area map and non-psychometric observed-behaviour lenses |
| AI-ready workplace bridge | Dedicated status-failure and AI-workplace debrief prompts |
| Session evidence | Decision record, history, timing, contribution metrics, debrief data, JSON export |
| Remote role cards | Each private terminal can archive its current unequal-information brief |
| Playtest measures | In-runtime ratings for clarity, thrill, survival, AI alignment, facilitation, role value, and Teams/Zoom fit |
| Kill/reframe condition | AI-alignment failure or explicit stop/reframe disposition raises a recorded warning |

The runtime intentionally does not claim psychometric validity or formal
leadership-readiness certification. Debrief outputs are structured learning
evidence from one simulated team decision, not a personnel assessment.

The only requirement that cannot be completed by code is empirical viability:
real participants must still test Teams/Zoom coordination, tension, one-person
facilitation load, and whether the AI-leadership transfer lands. The runtime now
captures those results and raises the document's stop/reframe warning when AI
alignment fails.
